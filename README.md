## 📌 Projeto em destaque

### Logistics Operations Data Platform

Plataforma de dados criada para simular uma operação logística real, desde a ingestão até o consumo analítico.

O projeto contempla:

- Ingestão de dados via arquivos e Azure SQL
- Arquitetura Medallion: Bronze, Silver e Gold
- Processamento com PySpark e Spark SQL
- Tabelas Delta Lake e cargas idempotentes
- Regras de qualidade e rastreabilidade de dados
- Pipeline orientado por metadados
- Testes e CI/CD com GitHub Actions
- Indicadores de SLA, atrasos e desempenho logístico

> Projeto em desenvolvimento e documentação contínua.
